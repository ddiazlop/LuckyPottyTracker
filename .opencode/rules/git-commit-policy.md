# Git Commit Policy

- **Never commit autonomously**: Under no circumstances should the agent run `git commit`. Only commit when the user explicitly requests or instructs it.
- **Always use the commit skill**: When asked to commit, follow the workflow and message standards in [.opencode/skills/commit/SKILL.md](file:///E:/Amazing/hiring-lab-0c132778-d863-4782-88a5-a74d35255902-ddiazlop/.opencode/skills/commit/SKILL.md).
